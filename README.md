# fleet-fatigue-detection-system

This problem is for solving problem of driver fatigue and micro-sleep events among heavy-driver vehicles such as bus and lorry drivers.

## Problem statement
Many road accidents  happen nowadays because of driver fatigue  that affect the driving performance. This may lead micro-sleeping behavior among truck drivers, which are concerning because it may occur before the collisions. Hence, accidents involving heavy vehicles such as lorry or bus will give bigger impacts than other vehicles.
