# Concepts
Technology in the field of artificial intelligence that allows machines to interpret and understand visual information automatically. The technology works by converting visual data such as images and videos into numerical data using AI models and can be processed by algorithms (Smith, 2024). In my project, this technology is used to detect or identify the signs of fatigue level and monitor the drivers in real time. The system records video and identifies the face of driver using image processing techniques, and evaluates the face features such as Ear Aspect Ratio (EAR) to detect driver drowsiness.  

# Frameworks
1. Flask
2. MediaPipe Face Landmaker  
3. PyTorch

# Models Used
1. Convolutional Neural Network (CNN)
2. You Only Look Once(YOLO)
3. Long Short-Term Memory (LSTM)


# Methods and algorithm
1. Eye Aspect Ration
2. Cumulative Microsleeoing Algorithm
3. Haar Cascade Algorithm 

# Fit
- Computer vision is the most suitable technology because it can monitor and detect the drivers fatigue sign through a camera with high accuracy

# Limitation
- Cannot detect eyes through sunglasses
- Poor Lighting
- Variation head pose

# Alternative
- EEG-based monitoring : Uses sensors to identify signs of drowsiness.

# Comparison 
Computer vision is chosen for this project because it can monitor drivers through camera without needing them to wear any tools but can still can detect the driver fatigue signs and record repeated micro-sleep events.
