# User Stories

1. As a lorry driver, I want the system detects the sign of fatigue while driving, so that i can receive early warning (NFR1).
Acceptance criteria : 
1.	Given that camera detects signs of fatigue, then the system shall display a fatigue level.
2.	Given that no signs of fatigue detected, then the system shall not trigger a warning unnecessarily.

 
2. As a lorry driver I want the system receive an alert when microsleep happens, so that I can avoid potential accidents (FR2).
Acceptance criteria:
1.	Given that a possible micro-sleep event is detected, the system shall record the event for analysis.
2.	Given that a driver’s eyes remain closed for a specific time, then the system shall give an immediate warning. 


3. As a fleet manager, I want the system is user friendly, so that I can easily understand the system results (NFR3).
Acceptance criteria :
1.	Given that fleet manager opens the dashboard, then the system shall display drivers’ performance in a clear format. 
2.	Given the fleet manager views the dashboard, then the system shall uses table for clear labels and understandable warnings.
