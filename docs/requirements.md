# Requirements

## Functional requirements (what the system must DO)
1. FR1 : The system shall detect signs of driver fatigue.
2. FR2 : The system shall send an alert when maximum level fatigue sign is detected.
3. FR3: The system shall record the microsleep events.
4. FR4 : The system shall show the driver performance.
5. FR5 : The system shall allow admin to view the drivers's fatigue history.


## Non-functional requirements (how the system must PERFORM)
1. NFR1 :  The system shall detect the signs of fatigue level within 2 seconds.
2. NFR2 : The system shall achieve a target detection accuracy of atleast 85%.
3. NFR3 : The system shall display the results in simple interface.
