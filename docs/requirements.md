# Requirements

## Functional requirements (what the system must DO)
1. The system shall detect signs of driver fatigue.
2. The system shall send an alert when sign maximum fatigue level are detected.
3. The system shall allow admin to view the drivers's fatigue history.


## Non-functional requirements (how the system must PERFORM)
1. The system shall detect the signs of fatigue level within 2 seconds.
2. The system shall achieve a target detection accuracy of atleast 85%.
3. The system shall display the results in simple interface.
